# Synthetic catalog notes

Device names identify real smartphone models. `device_version=1.0` is a fixed
synthetic hardware revision, not an OEM model code or an OS version.

OS profiles are conservative samples of supported major releases, not complete
update matrices. Huawei HarmonyOS entries describe Chinese-market firmware;
Android entries describe Android-based global firmware. Android skins such as
One UI, HyperOS and MagicOS are not treated as separate operating systems.

- Apple compatibility: https://support.apple.com/guide/iphone/iphone-models-compatible-with-ios-26-iphe3fa5df43/26/ios/26
- Pixel updates: https://support.google.com/pixelphone/answer/4457705
- Samsung device support: https://www.samsung.com/uk/support/mobile-devices/
- OnePlus updates: https://www.oneplus.com/global/support/softwareupgrade

Version ordering is explicit in each profile; consumers must not sort versions
lexicographically. The genre catalog is a synthetic vocabulary of real genres
and subgenres, not a claim of a universal classification.
