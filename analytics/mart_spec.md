# Витрина "music-stream-flow"

## Требования к витрине

Витрина разрабатывается для получения следующей информации:

### Топ используемых девайсов (модели телефона) (активно используемых - last_seen меньше недели)
Ключ: количество сессий
Результат: количество event, количество сессий

### Топ используемых девайсов (операционная система) (активно используемых - last_seen меньше недели)
Ключ: количество сессий
Результат: количество event, количество сессий

### Топ треков по прослушиваниям (selected)
Ключ: events_count со статусом "track_selected"
Результат: количество выборов (selections_count)

### Топ треков по лайкам за период
Ключ: likes_count со статусом "track_liked"
Результат: количество лайков (likes_count)

### Топ треков по лайкам за всё время
Ключ: likes_count со статусом "track_liked"
Результат: количество лайков (likes_count)

### Топ альбомов по прослушиваниям (selected)
Ключ: events_count со статусом "track_selected"
Результат: количество выборов (selections_count)

### Среднее время сессии пользователя (общее)
Результат: среднее время сессии

### Среднее время сессии пользователя (по пользователям)
Результат: среднее время сессии для каждого пользователя
