# Витрина "music-stream-flow"

## Требования к витрине

Витрина разрабатывается для получения следующей информации:
- Топ активно используемых девайсов (модели телефона) (активно используемых - last_seen меньше недели)
- Топ активно используемых девайсов (операционная система) (активно используемых - last_seen меньше недели)
- Топ треков по прослушиваниям (selected)
- Топ треков по лайкам по периодам/за всё время
- Топ альбомов по прослушиваниям (selected)
- Среднее время сессии пользователя (между started и ended/started и текущим временем)
- Топ прослушиваемых исполнителей (selected c исполнителем)
